# octano-anp-data

Arquivos públicos consumidos pelo app **Octano**:

- os dados da release [`latest`](../../releases/tag/latest), baixados pelo app;
- os Termos de Uso e a Política de Privacidade (`TERMOS*.md`, `PRIVACIDADE*.md`), lidos pelo app neste branch.

Os dados são registros públicos (ANP, Procons, IPEM, Senacon), republicados como foram publicados na origem, com data e fonte.

O código que coleta e organiza esses dados não faz parte deste repositório.
